# Event Hub Management System

A web-based event management system built using a microservices architecture.

## Features

- User Management
- Event Management
- Ticket Booking
- Payment Service
- Notification Service
- API Gateway
- Dockerized Services

## Technologies

- Java
- Spring Boot
- React
- MySQL
- REST API
- Microservices

## Project Structure

- API Gateway
- User Service
- Event Service
- Ticket Service
- Payment Service
- Notification Service
- Frontend (React)
